# Security policy

## Report a vulnerability

Do not open a public issue or pull request for a suspected vulnerability.
Open the [repository security advisories](https://github.com/AnnabiGihed/RaidManager/security/advisories) and select
**Report a vulnerability**. GitHub sends the report privately to the repository maintainers.

Include the affected component, reproduction steps, impact, and any suggested mitigation. Do not include credentials
or another person's private data in the report.
