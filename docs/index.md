# RaidManager documentation

RaidManager aims to coordinate Warmane raids using characters whose loadouts and lockouts are synchronized from
World of Warcraft 3.3.5a. The codebase is at the foundation stage.

- [Version 1 product scope and workflows](explanation/product.md) defines the complete player, officer,
  synchronization, readiness, and raid-night journeys.
- [Architecture and implementation status](explanation/architecture.md) separates the current scaffold from the
  intended integration.
- [API contract scope](reference/api-contracts.md) lists planned contract areas without inventing endpoints.
- [Glossary](glossary.md) defines the domain terms.
- [Architecture Decision Records](adr/README.md) explains the accepted decisions.

Build and test commands are in the repository's root README.
