# API contracts

The HTTP API is not yet implemented. The first public contracts will cover:

- Discord authentication session/profile endpoints;
- Warmane character lookup and profile retrieval;
- character claim and addon synchronization;
- loadout and raid-lockout retrieval;
- community and raid management;
- raid signup and roster management.

Transport DTOs must remain separate from Domain types.
OpenAPI becomes the contract source once the API slice is implemented.
